# Numbers and Keynote Compatibility Checklist

When an Apple iWork file must be shared with Windows users, choose the export format based on the task:

- Numbers → XLSX for editing, PDF for fixed-layout review;
- Keynote → PPTX for editing, PDF for slides without animation;
- Pages → DOCX for editing, PDF for reliable presentation.

[iWorkViewer](https://iworkviewer.com/) provides quick compatibility guidance for common `.pages`, `.numbers`, and `.key` files.

After conversion, check fonts, formulas, charts, animations, comments, and page breaks. Cross-platform exports can preserve the content while still changing the layout.
