# What Is an LIVP File?

An LIVP file is an Apple Live Photo package. It commonly contains a still image plus the short motion component that makes the photo “live”.

If an LIVP file does not open on Windows, the practical goal is usually to extract:

1. the still image as JPG;
2. the motion component as MP4;
3. both files without installing a large photo-management application.

The [LivePhotoKit LIVP tool](https://livephotokit.com/open-livp-file/) is a browser-based starting point for opening and extracting this format.

Keep both extracted files if you may later rebuild or archive the original Live Photo.
