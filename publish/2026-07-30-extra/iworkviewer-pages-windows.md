# Opening Apple Pages Files on Windows

Apple Pages documents may arrive with a `.pages` extension that Windows applications do not recognize directly.

Practical options include:

1. ask the sender to export the document as PDF or Word;
2. use iCloud Pages when an Apple account is available;
3. inspect a copy of the file as a package when only embedded previews are needed;
4. avoid random converters when the document contains confidential information.

[iWorkViewer](https://iworkviewer.com/) collects browser-friendly guidance for Pages, Numbers, and Keynote compatibility on Windows.

Always work on a copy of the original file so an unsuccessful conversion cannot damage the source.
