# A Simple Seed-Starting Timeline

Work backward from the expected last spring frost:

1. Find the local estimated last frost date.
2. Check the crop’s recommended indoor-start window.
3. Allow time for germination and early growth.
4. Add a hardening-off period before transplanting.
5. Delay outdoor planting if a late cold snap appears.

The location pages and crop guidance in [Planting Calendar](https://plantingcalendar.net/planting-calendar/) help turn those steps into a practical schedule.

Common mistakes include starting too early, using insufficient light, skipping hardening off, and treating an average frost date as a weather guarantee.
